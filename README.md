# ミミィのえいご

小学生向けの英語学習アプリ（PWA）。うさぎの「ミミィ」といっしょに、**耳で聞く → まねして言う → えらぶ・ならべる** をくりかえして、英検5級・4級の基礎単語と会話を身につけます。

## できること
- **きょうのレッスン**：新しいことば（1回3〜8こ）＋復習。正解するたびに次の出題までの日数がのびる（1→2→4→7→15→30日）
- **きいてタッチ / みみトレ**：音だけで絵や意味をえらぶ。thirteen/thirty、ship/sheep など似た音の聞き分け
- **いみクイズ / つづりパズル / かいわ / ならべかえ / ABC / ぶんぽう**
- **英検ミニテスト**（5級ふう・4級ふう、22問）
- **ことばずかん / きせかえ**（⭐でアイテムを買う）
- **はなすれんしゅう**（🎤：Chromeの音声認識。音声はGoogleのサーバーで処理されます）
- 複数人の切り替え、おためしモード（記録されない）、バックアップ書き出し

## ファイル
| ファイル | 中身 |
|---|---|
| index.html | 画面のデザイン |
| app.js | アプリのしくみ |
| data.js | 英検の単語・会話・文・文法のデータ |
| book.js | 単語の本（Lesson 2〜35）のことばと、レッスンにあわせた会話・文 |
| mg.js | まちがいさがしの自動生成 |
| pics.js | 絵文字がない ことばの オリジナルの絵（約190こ） |
| buddies.js | なかまキャラ（ミミィ・ニャメ・タマゴン・むすび・もっちー）の絵と表情 |
| sw.js | オフライン用（更新時は VERSION を上げる） |
| manifest.webmanifest, icon-*.png | ホーム画面に追加するための設定とアイコン |

記録は端末のブラウザ（localStorage）に保存され、外部には送られません（🎤だけは上記のとおり）。
